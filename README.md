# Analog-Digital Clock

A modern and attractive clock that combines both analog and digital time display. Built with HTML, CSS, and JavaScript.

## Features

- Beautiful analog clock with smooth-moving hands
- Integrated digital time display
- Modern dark theme with glowing effects
- Responsive design
- Animated decorative elements
- Interactive hover effects

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- JavaScript

## Preview

The clock features:
- Smooth hand movements
- Glowing circular animations
- Dark theme with red accents
- Digital time display with AM/PM indicator
- Interactive number markers

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. Enjoy the beautiful clock!
